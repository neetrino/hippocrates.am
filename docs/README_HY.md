# Hippocrates.am — փաստաթղթերի փաթեթ

Նվազագույն կտրվածքը հանված է (`ADR-003`)։ Գործող արտադրանքը canonical սպեցիֆիկացիան է։

## Կարևոր պարզաբանումներ

- Ամբողջ պրոյեկտը ներառում է հանրային որոնումը, ամրագրումը, մասնաճյուղերը, անձնական չատը, հանրային հարցուպատասխանը, կարծիքները և կլինիկայի աշխատանքը։
- Ֆինանսական կետը և կլինիկական կետը նույն պրոյեկտի հետագա կետերն են. դրանք չեն գրվում առաջին կետերի հետ։
- Փաստաթուղթը չի նշանակում, որ համապատասխան ծրագիրն արդեն գրված է։
