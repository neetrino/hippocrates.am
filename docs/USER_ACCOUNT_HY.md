# Պացիենտի հաշիվ — sidebar-ի դաշտեր

> Աղբյուրը `FR-009` է (`FUNCTIONALITY_HY.md`, canonical սպեցիֆիկացիա)։ Տեսքը նույն shell-ն է, ինչ Super Admin-ի վահանակը. ձախ sidebar, վերնագիր, բովանդակություն։ Դաշտերը միայն պացիենտի հաշվինն են։

Պացիենտը ինքն է գրանցվում և մտնում է իր հաշիվ (`/me`)։ Super Admin-ի կետերը (կլինիկաներ, հարթակի հարցերի մոդերացիա) այստեղ չեն։

## Հիմնական բաժիններ

| Դաշտ | Ինչ է ցույց տալիս |
| --- | --- |
| Վահանակ (`/me`) | Մոտակա այցը, ծանուցումների քանակը, ամրագրել այց, կարծիք չթողած ավարտված այց |
| Այցեր (`/me/visits`) | Երեք առանձին բաժին՝ սպասող (մինչև 4, հաստատվածն էլ այստեղ), ավարտված (մինչև 3), չեղարկված (մինչև 2). մնացածը բացվում է «Ավելին» կոճակով. ծառայության անունը հետևում է ընտրված լեզվին. հաստատել, չեղարկել, տեղափոխել. ավարտված այցից կարծիք |
| Նախընտրածներ (`/me/favorites`) | Պահած կլինիկաներ և բժիշկներ |
| Հարցեր (`/me/questions`) | Սեփական հարցերը և կարգավիճակը՝ սպասում է, հրապարակված, մերժված. հեղինակի անունը հանրային էջում չի երևում |
| Կարծիքներ (`/me/reviews`) | Ավարտված այցից թողած կարծիքները. ծառայության անունը հետևում է ընտրված լեզվին |

## Հաշվի բաժիններ

Sidebar-ի ներքևում, Super Admin-ի հաշվի բլոկի տեղում։

| Դաշտ | Ինչ է ցույց տալիս |
| --- | --- |
| Ծանուցումներ | Հավելվածի ծանուցումները. համակարգի տեքստը հետևում է ընտրված լեզվին. չկարդացածը առանձնանում է, բացելը գրում է կարդացած |
| Կարգավորումներ | Նկար, անուն և ազգանուն, էլ. փոստ, հայկական հեռախոս. սկզբում միայն դիտում, փոփոխությունը՝ Խմբագրել կոճակով. գաղտնաբառը առանձին |

Ելքը նույն բլոկի վերջում է։

## Այս հերթում չկա

- **Չատ.** Դադար է (`ADR-004`)։ Աղյուսակ, երթուղի և sidebar-ի կետ չավելացնել, մինչև սեփականատերը հետ չդնի հերթի մեջ։
- **Վճարումների պատմություն և կլինիկական քարտ.** Նույն պրոյեկտի հետագա կետեր են. այս վահանակի հետ չեն գրվում։
