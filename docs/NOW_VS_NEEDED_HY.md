# Hippocrates.am — ինչ ունենք հիմա և ինչ պետք է ավելացնել

> Թարմացվել է 2026-10-14։ Համեմատությունը `FUNCTIONALITY_HY.md` / `BRIEF.md` (`FR-001`…`FR-017`) և իրական կոդի միջև է (`apps/web`, `apps/api`, Prisma)։
> Եթե այս ֆայլը և կոդը չեն համընկնում, հաղթում են կոդը և հաստատված խնդիրը։ `docs/archive/` պատմական սպեց է, ոչ այսօրվա քարտեզ։
> «Կա» նշանակում է աշխատող երթուղի կամ էջ։ «Մասնակի» նշանակում է կա, բայց BRIEF-ի ամբողջ կետը դեռ չէ։

## Այս պահին կա

Հիմքը կանգնած է. մեկ Next.js կայք (`3000`), մեկ NestJS API (`4000`), մեկ PostgreSQL, չորս դեր։

| Տարածք | Ինչ կա հիմա |
| --- | --- |
| Դերեր | `SUPER_ADMIN`, `ADMIN`, `DOCTOR`, `PATIENT`։ Argon2id, cookie session, HttpOnly |
| Գրանցում | Պացիենտ՝ `/register`։ Super Admin՝ կլինիկա և Admin։ Admin՝ բժիշկ։ Կան `/forgot-password` և `/reset-password` |
| Հանրային կայք | Գլխավոր, կլինիկաների և բժիշկների ցանկեր ու էջեր, որոնում, ամրագրում ազատ ժամից, հարցեր։ `hy` / `en` / `ru` |
| Կատալոգ | Կլինիկա և բժիշկ՝ լոկալ տեքստ, նկար R2-ում, ծառայություն (գին, տևողություն, գնահատում, հրապարակում) |
| Հաստատում | `published` և `verificationStatus` առանձին են։ Նոր կլինիկան/բժիշկը `SUBMITTED` են։ Super Admin՝ `/super-admin/verification` |
| Ժամանակացույց | Կլինիկայի և բժշկի պատուհան, բացառություն, հանրային ազատ ժամ։ Բժշկի ժամը կլինիկայի պատուհանի մեջ է |
| Այց | Խնդրել, սեղանի ամրագրում, հաստատել, չեղարկել, տեղափոխել, ավարտել, չներկայանալ, չհաստատվածի `EXPIRED`։ Occupancy՝ `REQUESTED` և `CONFIRMED` |
| Պատմություն | `AppointmentEvent` (append-only)։ Այցի քարտում timeline՝ `/clinic/visits`, `/me/visits`, պացիենտի քարտ |
| Ծանուցում | In-app `Notification`, հիշեցման տողեր inbox-ում։ Այցի email/SMS չկա (Resend-ը միայն reset-ին է) |
| Հարցեր | Հանրային ուղարկում և ցանկ, բժշկի պատասխան, Super Admin էջ։ Հանրային DTO-ում հեղինակ չկա |
| Կարծիք | Միայն `COMPLETED` այցից։ Պացիենտը գրում է իր էջից, կլինիկան պատասխանում է |
| Վահանակներ | Պացիենտ, բժիշկ, կլինիկայի սեղան, Super Admin։ Նախընտրած և կարգավորում կան |
| Փորձի տվյալ | `pnpm db:seed` |

## Մասնակի է

- Կլինիկաների ցանկում թաղամասը երևում է, որպես ֆիլտր դեռ չկա։
- `AppointmentEvent` կա, check-in / hold / չեղարկման cutoff չկան։
- Notices-ը inbox է, ոչ email delivery engine։
- Հաստատումը կարգավիճակով է. ապացույցի ֆայլ և ժամկետ դեռ չկան։
- Super Admin հարցերի էջը կա. լիարժեք մոդերացիա և հարցերի որոնում դեռ նեղ են։

## Ինչ պետք է ավելացնել

Հերթը `FUNCTIONALITY_HY.md`-ի կետերն են։ Ստորև միայն այն մասն է, որը դեռ չկա կամ մասնակի է։

### Կայքի հանրային մաս

- **FR-001.** Ինտերֆեյսի երեք լեզուն, գրանցումը և որոնումը կան։ Email-ի հաստատում գրանցումից հետո չկա։
- **FR-002.** Անունով և մասնագիտությամբ որոնումը կա։ Թաղամաս, գին, գնահատական, ազատ ժամ, լեզու որպես ֆիլտր դեռ ամբողջական չեն։
- **FR-003.** Կլինիկայի էջում կան բժիշկ, գին, կարծիք, կոնտակտ և ամրագրում։ Սարքավորում և վկայական չկա։ Առանձին `Branch` աղյուսակ չկա։
- **FR-004.** Բժշկի էջում կան մասնագիտություն, աշխատավայր, գին և ազատ ժամ։ Որակավորում և լեզուներ չկան։

### Ամրագրում և ծանուցում

- **FR-005.** Հիմա կա կլինիկա+բժիշկ առաջարկ։ Ընդհանուր ծառայության առանձին սահմանում չկա։
- **FR-006.** Պատուհանն ու բացառությունը կան (API և կլինիկայի/բժշկի ժամեր)։ Սենյակ/աթոռ/սարք չկա։
- **FR-007.** `NO_SHOW`, `EXPIRED`, `AppointmentEvent` և քարտի պատմությունը կան։ Hold, check-in և չեղարկման cutoff չկան։
- **FR-008.** In-app գրառում և inbox հիշեցում կան։ Այցի էլ. փոստ և SMS չկան։

### Վահանակներ

- **FR-009.** Այց, ծանուցում, հարց, կարծիք, նախընտրած, կարգավորում կան։ Չատը դադար է։
- **FR-010.** Բժիշկը տեսնում է այցերը և պատասխանում է հարցին։ Առանձին ամփոփում և չատ չկան։
- **FR-011.** Անձնական չատ։ Դադար է (`ADR-004`)։ Աղյուսակ և երթուղի չավելացնել, մինչև սեփականատերը հետ չդնի հերթի մեջ։
- **FR-015.** Կլինիկա՝ անձնակազմ, ծառայություններ, այցեր, պացիենտի քարտ, կարծիք, ֆինանսի հանրագումար։ Մասնաճյուղերի առանձին էջ և իրավունքների մատրից չկան։

### Հանրային բովանդակություն և հարթակ

- **FR-012.** Հարց ուղարկելու և Super Admin էջերը կան։ Մոդերացիան դեռ նեղ է։
- **FR-013.** Հարցերի ցանկը կա, արխիվային որոնում չկա։
- **FR-014.** Կարծիք և կլինիկայի պատասխան կան։ Վեճի հոսք չկա։
- **FR-016.** Verification հերթ և կլինիկաների ցանկ կան։ CMS, լիարժեք աուդիտ և պլանի տեսանելիություն չկան։
- **FR-017.** `verificationStatus` + հերթ կան։ Ապացույցի ֆայլ, ժամկետ և ինքնուրույն ուժը կորցնել չկան։

### Նույն պրոյեկտի հետագա կետերը

Սրանք չեն գրվում վերևի կետերի հետ։

- Ֆինանս՝ իրական վճարում, վերադարձ, հաշիվ, բաժանորդագրություն։ Հիմա միայն գների հանրագումարն է։
- Կլինիկական՝ քարտ, նշում, բուժման պլան, վիրահատություն, պատկերներ։
- Թողարկում՝ production հոսթ, տարածաշրջան, պահուստի և դեպլոյի պատասխանատու դեռ անուն չունեն։

## Հաջորդ քայլը

Աշխատող կայքը կանգնած է։ Մոտ բացերը BRIEF-ի մնացորդներն են (օր. թաղամաս-ֆիլտր, այցի email, check-in), ոչ հանրային բժշկի էջը կամ ամրագրումը։ Չատը, վճարումը և կլինիկական քարտը այս հերթում չեն։ Կետերի կարգը՝ `PROGRESS.md`։
