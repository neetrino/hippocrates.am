# Hippocrates.am — Minimum MVP փաստաթղթերի փաթեթ

**Ստեղծվել է՝ 29.09.2026։ Կարգավիճակ՝ նախագծային տարբերակ, սպասում է Product Owner-ի վերջնական հաստատմանը։**

Այս փաթեթը վերափոխում է Hippocrates.am-ի նախորդ ընդլայնված Version 1 փաստաթղթերը՝ համապատասխանեցնելով միայն Ձեր առանձնացրած **23 նվազագույն գործառույթներին**։ Տեխնիկական փաստաթղթերը պահպանված են անգլերենով, իսկ պաշտոնական ֆունկցիաների ցանկը՝ հայերենով։

## Ներառված ֆայլերը

- `docs/FUNCTIONALITY_MINIMUM_HY.md` — Ձեր 23 ֆունկցիաները՝ նույն հերթականությամբ։
- `docs/BRIEF.md` — նոր նվազագույն MVP-ի նպատակները, բոլոր 23 ֆունկցիաների ընդունման պայմանները, դերերը և բացառությունները։
- `docs/TECH_CARD.md` — նվազագույն համակարգի նախագծային տեխնիկական քարտը և հաստատման ենթակա ընտրությունները։
- `docs/01-ARCHITECTURE.md` — թեթև ճարտարապետություն, մոդուլներ և ամրագրման անվտանգ աշխատանք։
- `docs/02-TECH_STACK.md` — տեխնոլոգիաները՝ առանց ավելորդ ենթակառուցվածքի։
- `docs/03-STRUCTURE.md` — նախագծի առաջարկվող թղթապանակների և մոդուլների կառուցվածքը։
- `docs/04-API.md` — միայն նվազագույն ֆունկցիոնալության համար նախատեսված API-ի նախագիծը։
- `docs/05-DATABASE.md` — նվազագույն տվյալների մոդելը և ամրագրումների համընկնումներից պաշտպանությունը։
- `docs/DECISIONS.md` — բաց հարցերը, հին և նոր շրջանակների փոփոխության գրանցումը։
- `docs/PROGRESS.md` — մշակման փուլերը, ստուգումները և փաստացի առաջընթացի գրանցման կանոնները։
- `docs/SCOPE_CHANGE.md` — ինչն է պահպանված, և ինչն է հանված նախորդ 46 ֆունկցիաներից։
- `docs/architecture/adrs/ADR-001-MINIMUM-MVP-SCOPE.md` — շրջանակի կրճատման նախագծային որոշումը (դեռ չհաստատված)։

## Կարևոր պարզաբանումներ

- Անձնական չատը, հանրային հարցուպատասխանը, ընդլայնված մոդերացիան, վճարումները և բժշկական քարտերը **այս նվազագույն տարբերակում չեն ներառվում**։
- Մեկ կլինիկայում բժշկի ակտիվ գործունեությունը և մեկ հասցեով կլինիկայի աշխատանքը **առաջարկված պարզեցումներ են**, որոնք անհրաժեշտ է Ձեր կողմից հաստատել։ Դրանք բառացի պահանջներ չեն 23 ֆունկցիաների ցանկում։
- Մարդկանց իրավունքների, տվյալների պաշտպանության, այցերի կրկնակի ամրագրման և պահուստավորման հիմնական ստուգումները պահպանված են՝ որպես պարտադիր տեխնիկական պայմաններ։
- Փաստաթղթերի ստեղծումը **չի նշանակում**, որ համապատասխան ծրագիրն արդեն մշակված կամ ստուգված է։ AI Agent-ը նախ ուսումնասիրում է իրական repository-ն։
- Փաթեթը չի փոխում Ձեր սկզբնական ֆայլերը և չի ջնջում հին Version 1 փաստաթղթերը։ Այն պատրաստ է վերանայման և անվտանգ միավորման համար։

**Առաջարկվող ընթերցման հերթականություն AI Agent-ի համար՝** `FUNCTIONALITY_MINIMUM_HY.md` → `BRIEF.md` → `SCOPE_CHANGE.md` → `TECH_CARD.md` → `01-ARCHITECTURE.md` → `02-TECH_STACK.md` → առաջադրանքին առնչվող API/DB → `DECISIONS.md` → `PROGRESS.md`։
