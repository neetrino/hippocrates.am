# Hippocrates.am — ինչ ունենք հիմա և ինչ պետք է ավելացնել

> Թարմացվել է 2026-09-30։ Համեմատությունը արված է `FUNCTIONALITY_HY.md` / `BRIEF.md` (`FR-001`…`FR-017`) և իրական կոդի միջև (`apps/web`, `apps/api`, Prisma)։  
> «Կա» նշանակում է աշխատող երթուղի կամ էջ։ «Մասնակի» նշանակում է API կամ նեղ ձև կա, բայց սպեցի էջը դեռ չկա։

## Այս պահին կա

Հիմքը կանգնած է. մեկ Next.js կայք (`3000`), մեկ NestJS API (`4000`), մեկ PostgreSQL, չորս դեր։

| Տարածք | Ինչ կա հիմա |
| --- | --- |
| Դերեր | `SUPER_ADMIN`, `ADMIN`, `DOCTOR`, `PATIENT`։ Գաղտնաբառը hash է, սեսիան cookie-ով է |
| Գրանցում | Պացիենտը ինքն է գրանցվում (`/register`)։ Super Admin-ը կլինիկա և Admin է ստեղծում (`/platform`)։ Admin-ը բժիշկ է ստեղծում իր կլինիկայի համար (`/clinic`) |
| Հանրային կայք | Գլխավոր, կլինիկաների և բժիշկների ցանկեր՝ որոնումով, կլինիկայի և բժշկի էջեր՝ նկարով, գներով, կարծիքով և ամրագրմամբ ազատ ժամից։ Հարցերի էջ։ Տեսքը հայերեն, անգլերեն և ռուսերեն է |
| Կատալոգ | Կլինիկա՝ թաղամաս և կազմ R2-ում, մասնաճյուղ, բժիշկ՝ լուսանկարով, ծառայություն (անուն, գին դրամով, տևողություն, գնահատում/ֆիքսված, հրապարակում) |
| Ժամանակացույց | Աշխատանքային պատուհան, բացառություն, հանրային ազատ ժամեր էջում |
| Այց | Խնդրել, հաստատել, չեղարկել, տեղափոխել, ավարտել։ Կարգավիճակներ՝ `REQUESTED`, `CONFIRMED`, `CANCELLED`, `COMPLETED` |
| Ծանուցում | Հավելվածի ներսում գրառում (`Notification`) և `GET /me/notifications` |
| Հարցեր | Պացիենտը հարց է ուղարկում, բժիշկը պատասխանում է, Super Admin-ը հրապարակում է։ Հանրային ցանկում հեղինակը չի երևում |
| Կարծիք | Միայն ավարտված այցից հետո։ Պացիենտը գրում է «Իմ էջից», կլինիկայի էջը ցույց է տալիս |
| Կլինիկայի սեղան | Ադմինը տեսնում է իր կլինիկայի այցերը, բժիշկներին և գները, հաստատում կամ ավարտում է այցը։ Id ձեռքով չի մուտքագրում |
| Տվյալ փորձի համար | `pnpm db:seed` լցնում է 3 կլինիկա, 6 բժիշկ, գրաֆիկ, ավարտված այց, կարծիք և 2 հարց։ Նկարները գնում են R2 |
| Լեզու | Ինտերֆեյսը `hy`, `en`, `ru` է (`next-intl`)։ Հայերենը լռելյայն է (`/`), անգլերենը `/en`, ռուսերենը `/ru`։ Կլինիկայի և բժշկի տեքստը մնում է այնպես, ինչպես գրված է բազայում |

## Մասնակի է (կա, բայց սպեցի էջը դեռ չէ)

- Գրաֆիկի պատուհանը դրվում է seed-ով և API-ով։ Ադմինի էջում օրացույցով խմբագրում չկա։
- «Իմ էջը» ունի այցեր, ծանուցում, կարծիք և հարց։ Նախընտրած և կարգավորում չկա։ Բժիշկը նույն էջից պատասխանում է հրապարակված հարցին։
- Կլինիկան և բժիշկը ստեղծվելուն պես `published = true` են։ Առանձին հաստատում, մերժում, ժամկետ և ուժը կորցնել չկա։
- Որոնումը անունով և մասնագիտությամբ է։ Թաղամասը երևում է քարտի վրա, որպես ֆիլտր դեռ չկա։

## Ինչ պետք է ավելացնել

Հերթը `FUNCTIONALITY_HY.md`-ի կետերն են։ Ստորև միայն այն մասն է, որը դեռ չկա կամ մասնակի է։

### Կայքի հանրային մաս

- **FR-001.** Ինտերֆեյսի երեք լեզուն և որոնման դաշտը կան։ Բազայում պահված կլինիկայի ու բժշկի տեքստը դեռ մեկ լեզվով է։
- **FR-002.** Ֆիլտրեր՝ տարածք, ծառայություն, գին, գնահատական, ազատ ժամ, լեզու։ Անունով և մասնագիտությամբ որոնումը կա։
- **FR-003.** Կլինիկայի էջում կան մասնաճյուղ, բժիշկ, գին, կարծիք, կոնտակտ և ամրագրում։ Սարքավորում և վկայական չկա։
- **FR-004.** Բժշկի էջում կան մասնագիտություն, աշխատավայր, գին և ազատ ժամ։ Որակավորում և լեզուներ չկան։

### Ամրագրում և ծանուցում

- **FR-005.** Ընդհանուր ծառայության սահմանում, առանձին մասնաճյուղային առաջարկից։ Հիմա կա միայն կլինիկա+բժիշկ առաջարկ։
- **FR-006.** Ռեսուրսներ (սենյակ, աթոռ, սարք) և գրաֆիկի էջ։ Պատուհանն ու բացառությունը միայն API-ում են։
- **FR-007.** Չներկայանալ (`NO_SHOW`), ներկայության առանձին քայլ, անփոփոխ պատմություն։ Հիմա կա հաստատել, չեղարկել, տեղափոխել, ավարտել։
- **FR-008.** Էլ. փոստով ծանուցում և հիշեցում։ SMS միայն մատակարար և համաձայնություն լինելուց հետո։ Հիմա միայն ներսի գրառումն է։

### Վահանակներ

- **FR-009.** Պացիենտի էջում կան այց, ծանուցում, հարց և կարծիք։ Նախընտրած և կարգավորում չկա։
- **FR-010.** Բժիշկը տեսնում է իր այցերը և պատասխանում է հրապարակված հարցին։ Առանձին գրաֆիկի էջ և ամփոփում չկա։
- **FR-011.** Անձնական չատ։ Այս պահին դադար է (`ADR-004`)։ Աղյուսակ, երթուղի և էջ չավելացնել, մինչև սեփականատերը հետ չդնի հերթի մեջ։
- **FR-015.** Կլինիկա՝ մասնաճյուղերի էջ, անձնակազմի իրավունքներ, գործառնական պացիենտի գրառում, օրացույց, կարծիքների կառավարում, հասկանալի վահանակ առանց ձեռքով id-ի։

### Հանրային բովանդակություն և հարթակ

- **FR-012.** Հարց ուղարկելու էջ, մոդերացիայի էջ։ API-ի հրապարակել/մերժել կա, էջ չկա։
- **FR-013.** Հարցուպատասխանի որոնում։ Ցանկը կա, որոնում չկա։
- **FR-014.** Կարծիք թողնելու էջ ավարտված այցից, վեճ։ Պատասխանը միայն API-ում է։
- **FR-016.** Հարթակ՝ հաստատման հերթ, բովանդակություն, մոդերացիա, վիճակագրություն, աուդիտ։ Հիմա Super Admin-ը միայն կլինիկա է գրանցում։
- **FR-017.** Կազմակերպության և բժշկի հաստատում, ժամկետ, ուժը կորցնել։ Հիմա գրանցումը միանգամից հրապարակում է։

### Նույն պրոյեկտի հետագա կետերը

Սրանք չեն գրվում վերևի կետերի հետ։

- Ֆինանս՝ իրական վճարում, վերադարձ, հաշիվ, բաժանորդագրություն։ Հիմա միայն գների հանրագումարն է, քարտով վճարում չկա։
- Կլինիկական՝ քարտ, նշում, բուժման պլան, վիրահատություն, պատկերներ։ Յուրաքանչյուրը իր ընդունման սպեցով։
- Թողարկում՝ production հոսթ, տարածաշրջան, պահուստի և դեպլոյի պատասխանատու դեռ անուն չունեն։

## Հաջորդ քայլը

Կայքի կողմից ամենամոտ բացը հանրային էջերն են. բժշկի էջ, ֆիլտրով ցանկեր, ամրագրում ազատ ժամից, և կլինիկայի/պացիենտի վահանակներ՝ առանց ձեռքով id մուտքագրելու։ Չատը, վճարումը և կլինիկական քարտը այս հերթում չեն։
